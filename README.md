## 📈 NEPSE Quantitative Trading Methodology

I operate as an active quantitative swing trader in the Nepal Stock Exchange (NEPSE) with an execution horizon of 1 to 2 weeks, anchored by four strict technical pillars:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                                  THE 4 TRADING PILLARS                                  │
├──────────────────────────┬──────────────────────────┬──────────────────────────────────┤
│ 1. Price Action          │ 2. Volume Spread (VSA)   │ 3. Floorsheet Flow & Brokers     │
│ Supply & demand zones,   │ Volume confirmation on   │ Real-time broker accumulation,   │
│ break of structure (BOS),│ breakouts; identifying   │ top buyer/seller concentration,  │
│ multi-timeframe swings.  │ institutional absorption.│ delivery vs trading volume.      │
├──────────────────────────┴──────────────────────────┴──────────────────────────────────┤
│ 4. Strict Capital Preservation: Min 1:2.5 Risk-to-Reward Ratio • Max 2% Portfolio Risk │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Open Financial Transparency**: Authored [`nepse-floorsheet-archive`](https://github.com/jagdishsah126/nepse-floorsheet-archive) to liberate NEPSE data into free daily CSVs so independent Nepali developers and traders never face commercial subscription paywalls.
